# 拾集 · 本地文件索引与资源管理

作者：**YinL.**

当前版本：**第二测试版 1.1.0**

拾集是一款本地优先的 Windows 文件索引工具。选择电脑中的文件后，拾集只记录文件名、大小、更新时间和完整路径，不复制原文件。之后可以通过名称、说明、标签、分类、专区或路径快速找到文件，并直接打开原文件、在资源管理器中定位或复制完整路径。

![拾集文件索引与资源表格](assets/release/1.1.0-table.png)

## 核心用途

- 为电脑里分散的文件建立可搜索的路径索引。
- 按文件名、描述、标签、分类和完整路径搜索。
- 在详情页打开文件、定位所在文件夹或复制路径。
- 使用卡片、紧凑列表、画廊和表格浏览索引结果。
- 通过文件夹、资料库、自定义专区和 Minecraft 专区组织内容。
- 在索引文件之外，附带管理链接、笔记和本地账号。

## 1.1.0 主要能力

- “全部资源”保留文件类型筛选，集中查看文件数量与索引内容。
- 文件卡片和表格优先展示本地路径，详情页提供“打开文件”“在文件夹中显示”和“复制路径”。
- 左侧边栏按“资料库 / 专区 / 账号 / 分类”分组。
- “全部资源”可包含并筛选通用资源库、Minecraft 和所有自定义专区。
- 自定义专区支持模板、名称、说明、图标、配色、允许的内容类型、默认排版和账号入口。
- 个性化支持浅色、深色、跟随系统，以及七套完整主题配色。
- 界面字号支持小、标准、大、特大；侧栏字号可单独调整。
- 资源详情支持窗口式和侧边式，并可记忆选择。
- 搜索、新建、切换外观、打开账号和打开设置支持自定义快捷键。
- 关闭窗口可设置为退出软件或收起到系统托盘。
- 支持多级窗口返回、图片预览、完整 JSON 备份和恢复初始状态。

## 文件索引说明

桌面版通过系统文件选择器或文件拖放取得文件路径，只保存：

- 文件名和扩展名
- 文件大小
- 最后修改时间
- 完整本地路径
- 用户填写的标题、说明、标签和分类

原文件不会复制进拾集，也不会在清理索引时被删除。移动或删除原文件后，索引中的路径会失效，需要在资源详情中重新选择文件。

## 本地数据

- 资源、分类和账号保存在当前设备的 IndexedDB 中。
- 桌面版偏好保存在应用数据目录。
- 账号保险箱不提供主密码或云端同步，请保护 Windows 账户和导出的备份文件。
- JSON 备份包含资源、文件路径、账号和个性化设置。

## 本地运行

项目不依赖 Node.js、Python 或第三方前端库。Windows 下运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\server.ps1
```

然后访问 [http://localhost:4173](http://localhost:4173)。

## Windows 桌面版

构建命令：

```powershell
pwsh -NoProfile -ExecutionPolicy Bypass -File .\desktop\build-windows.ps1
```

构建输出：

```text
release/拾集/
release/拾集-第二测试版-1.1.0-Windows-x64.zip
```

桌面版使用独立的应用数据目录，不会读取浏览器版数据。需要迁移时，先在网页版导出 JSON，再在桌面版“设置与备份”中导入。

## 项目结构

```text
.
├─ index.html                 页面骨架、导航、弹窗与图标
├─ app.css                    主题、布局、组件与动效
├─ js/
│  ├─ store.js                IndexedDB 数据仓库
│  └─ app.js                  应用状态、文件索引、视图与交互
├─ server.ps1                 本地 HTTP 预览服务
├─ desktop/                   Windows 桌面封装与构建
├─ release/                   可运行目录与发布包
└─ assets/                    图标、头像与界面预览
```

## 当前限制

- 1.1.0 仍为第二测试版，不代表最终正式发布品质。
- 文件索引依赖原文件位置，不自动跟踪跨磁盘移动。
- 账号密码保存在本机，没有云端同步或独立加密。
- 网页版仍将小文件保存在浏览器数据库，单文件上限为 50 MB。
- 网站图标抓取可能受目标站点限制或网络环境影响。
