拾集 · 第二测试版 1.2.12（Windows 桌面版）

当前是第二测试版本，尚不属于正式发布版。
拾集用于统一管理本地文件、链接、笔记、账号和创作素材。

运行：
1. 解压整个“拾集”文件夹。
2. 双击“拾集.exe”启动。
3. 不要把 exe 单独复制出去，程序需要同目录中的 resources 等文件。

数据位置：
资源、分类和账号保险箱保存在当前 Windows 用户的拾集应用数据目录中。
清理浏览器数据不会影响桌面版数据。

文件索引：
电脑版只记录原文件路径，不会复制或移动大文件。
在文件详情中可以直接打开原文件，或点击文件夹按钮定位到所在目录。
也可以通过复制路径按钮取得完整文件路径。
如果移动或删除原文件，拾集中的路径会失效，需要重新选择。

素材库位置：
首次启动会要求选择素材库和缓存位置。
以后导入的通用资源、录屏原片、材质包、转场、封面和成片会按类型自动归档。
复制模式会保留原文件，移动模式会减少重复占用空间。
已有素材和剪辑工程默认保留原位置，不会被首次设置自动搬动。
可在“设置与备份 → 素材库位置”中重新查看或修改。

素材库：
1. 在左侧打开“素材库”。
2. 首次进入会看到两张与普通素材相同样式的初始卡片。
3. 初始卡片可以修改名称、设置素材类型与说明，也可以进入详情查看信息。
4. 上传第一份真实素材后，初始卡片会自动隐藏。
5. 使用“上传素材”选择文件，或用“扫描文件夹”批量加入素材。
6. 素材会按类型保存到已经设置的素材库目录。
7. 点击素材卡片可以浏览文件信息。
8. 视频和音频可以直接在拾集中播放。
9. 需要剪辑时点击“打开所在文件夹”，再从 Windows 资源管理器把文件拖入剪映、PR 或其他软件。

重命名：
点击视频/音频素材卡片中的重命名按钮，会直接打开播放窗口并在顶部显示文件名输入框。
图片等非播放素材会在素材详情窗口顶部显示文件名输入框。
修改后点击“保存名称”，新名称会同步写入电脑文件。
文件扩展名保持不变；如果采用复制入库，入库前保留的原文件也会同步改名。
如果目标文件夹中已经存在相同名称，拾集会停止操作并提示冲突，不会覆盖文件。

封面：
录屏素材会尝试自动截取画面作为卡片封面。
点击素材播放按钮后，可以把当前视频画面直接生成素材封面。

删除素材：
“仅从拾集移除”只删除软件中的素材记录，不删除电脑上的源文件。
“删除源文件”会把素材库中的文件移入 Windows 回收站；如果采用复制入库，入库前保留的原始文件也会一起处理，同时从拾集中移除。

从网页版迁移：
1. 在网页版“设置与备份”中导出 JSON。
2. 在桌面版中进入“设置与备份”，选择该 JSON 文件恢复。

账号保险箱：
无需主密码，打开“账号保险箱”即可直接使用。
账号密码只保存在本机，请妥善保护 Windows 账户和导出的备份文件。

系统要求：
Windows 10/11 64 位。
